# ai-programming

## 簡単な電卓アプリ

`calculator.py` は、足し算、引き算、掛け算、割り算ができるシンプルな電卓です。

### 実行方法

1. ターミナルで、このプロジェクトのフォルダーに移動します。
2. 次のコマンドを実行します。

```bash
python3 calculator.py
```

3. 画面の案内に従って、数値と演算子を入力します。

例:

```text
1つ目の数値: 10
演算子 (+, -, *, /): *
2つ目の数値: 3
答え: 30
```

最初の数値を `q` と入力すると終了できます。数字以外を入力した場合や、0で割ろうとした場合はエラーメッセージが表示され、もう一度入力できます。
